🚀 Crear Apps con UTPyApps

Aprende a crear aplicaciones Python con Microdot para Ubuntu Touch

UTPyApps usa el framework Microdot para crear aplicaciones web ligeras. Cada app es un módulo Python independiente con sus propias rutas, templates y archivos estáticos.

1 Estructura de una App

Cada app en UTPyApps tiene esta estructura:

apps/mi_app/ ├── main.py # Código principal (endpoints) ├── app.json # Configuración y dependencias ├── templates/ # Templates Jinja2 │ └── index.html └── static/ # Archivos estáticos (opcional) ├── css/ ├── js/ └── images/

2 main.py - Código Principal

El archivo main.py define la aplicación Microdot y sus endpoints:

from microdot import Microdot, Response from jinja2 import Environment, FileSystemLoader import os # Crear aplicación app = Microdot() Response.default_content_type = 'text/html' # Configurar templates TEMPLATES_DIR = os.path.join(os.path.dirname(__file__), 'templates') app_env = Environment(loader=FileSystemLoader(TEMPLATES_DIR)) @app.route('/') def home(request): """Página principal""" template = app_env.get_template('index.html') html_content = template.render( app_name='Mi App', app_description='Descripción' ) return Response(html_content) @app.route('/api/hello') def api_hello(request): """Endpoint API""" return Response({ 'message': 'Hola!' }, headers={'Content-Type': 'application/json'})

3 Templates Jinja2

Los templates usan Jinja2 para contenido dinámico:

<!-- Variable --> <h1>{{ app_name }}</h1> <!-- Condición --> {% if user_logged_in %} <p>Bienvenido</p> {% endif %} <!-- Bucle --> {% for item in items %} <p>{{ item }}</p> {% endfor %}

4 API Endpoints

Crea endpoints JSON para comunicación con JavaScript:

@app.route('/api/data', methods=['POST']) def api_data(request): data = request.json return Response({ 'result': data['value'] * 2 }, headers={'Content-Type': 'application/json'})

5 app.json - Configuración

Define metadatos y dependencias de la app:

{ "name": "Mi App", "description": "Descripción de la app", "author": "Tu Nombre", "version": "1.0.0", "icon": "icon.png", "requirements": [ "requests>=2.25.0", "pandas>=1.3.0" ] }

6 Crear una Nueva App

Hay dos formas de crear una app:

🌐 Método Web: Ve al dashboard y haz clic en "Nueva App"

📁 Método Manual: Crea la carpeta en apps/ con los archivos necesarios
