🚀 Guía de UTPyApps

Crea aplicaciones Python para Ubuntu Touch de forma sencilla

UTPyApps es un framework que te permite crear aplicaciones web ligeras usando Python. Cada app es independiente y puede tener sus propias rutas, plantillas y archivos estáticos.

1 ¿Qué es UTPyApps?

UTPyApps es un sistema para crear aplicaciones web que corren en Ubuntu Touch. Usa el framework Microdot, que es ideal para aplicaciones ligeras y rápidas.

✨ Características principales:

  • Aplicaciones web ligeras con Python
  • Sistema de plantillas con Jinja2
  • Gestión de dependencias automática
  • Editor de código integrado
  • Despliegue en dispositivos Ubuntu Touch

2 Estructura de una App

Cada aplicación tiene una estructura simple y organizada:

apps/mi_app/ ├── main.py # Código principal de la app ├── app.json # Configuración y dependencias ├── templates/ # Plantillas HTML │ └── index.html └── static/ # Archivos estáticos (opcional) ├── css/ ├── js/ └── images/

main.py contiene la lógica de tu aplicación, app.json la configuración, templates las plantillas HTML y static los archivos estáticos como CSS e imágenes.

3 Crear una Nueva App

Hay dos formas de crear una aplicación:

🌐 Método Web (Recomendado):

Ve al dashboard principal y haz clic en el botón "Nueva App". Completa el formulario con el nombre, descripción y dependencias de tu app.

📁 Método Manual:

Crea una carpeta en apps/ con los archivos necesarios siguiendo la estructura mostrada arriba.

4 Conceptos Clave

Para crear aplicaciones efectivas, necesitas entender estos conceptos:

🔗 Rutas (Routes):

Definen las URLs de tu aplicación. Cada ruta responde a una petición específica y puede devolver HTML, JSON u otros datos.

🎨 Plantillas (Templates):

Usan Jinja2 para crear HTML dinámico. Puedes usar variables, condiciones y bucles para personalizar el contenido.

📡 APIs:

Los endpoints JSON permiten que tu JavaScript se comunique con el backend. Útiles para formularios, datos dinámicos, etc.

📦 Dependencias:

En app.json puedes especificar las librerías Python que necesita tu app. UTPyApps las instalará automáticamente.

5 Ejemplo Simple

Este es un ejemplo básico de una aplicación que muestra "Hola Mundo":

# main.py from microdot import Microdot, Response from jinja2 import Environment, FileSystemLoader import os app = Microdot() TEMPLATES_DIR = os.path.join(os.path.dirname(__file__), 'templates') app_env = Environment(loader=FileSystemLoader(TEMPLATES_DIR)) @app.route('/') def home(request): template = app_env.get_template('index.html') return Response(template.render(nombre='UTPyApps'))

Y en el template index.html:

<h1>Hola {{ nombre }}</h1>

6 Despliegue en Dispositivo

Para desplegar tu app en un dispositivo Ubuntu Touch:

  • Conecta tu dispositivo vía ADB
  • Usa el ADB Manager para configurar el entorno
  • Tu app se copiará automáticamente al dispositivo
  • Puedes iniciar/detener apps desde el dashboard
